Introdução

O labSIS-KIT possui uma implementação nativa de Notification Center para o Filament PHP v5, sem dependência de plugins ou pacotes de terceiros. Esse sistema enriquece o menu de notificações no topo (Topbar) do painel com abas categorizadas, contagens independentes em tempo real e paginação integrada via Livewire.

A arquitetura substitui completamente o uso de plugins externos por serviços locais e altamente otimizados em App\Support\NotificationCenter e App\Livewire\NotificationCenter.

Arquitetura e Diferenciais

O sistema foi construído sobre três pilares de software limpo e extensível:

  • NotificationCategory: Classe DTO fluente em App\Support\NotificationCenter que define identificadores, rótulos (labels), ícones (Heroicons), cores e ordenação das abas.
  • NotificationCenterManager: Gerenciador estático global de categorias por painel, inicializado automaticamente no AppServiceProvider. Ele também registra a macro nativa ->category() no modelo de notificações do Filament.
  • App\Livewire\NotificationCenter: Componente visual Livewire (declarado em BasePanelProvider) que substitui a renderização padrão e filtra as notificações no banco de dados utilizando consultas Eloquent precisas no JSON de metadados (data->viewData->category).

Como Registrar Categorias

As categorias são registradas por painel dentro do método panel() do respectivo PanelProvider (como AdminPanelProvider.php ou UserPanelProvider.php), utilizando o NotificationCenterManager:

php
<?php

use App\Support\NotificationCenter\NotificationCategory;
use App\Support\NotificationCenter\NotificationCenterManager;
use Filament\Support\Colors\Color;
use Filament\Support\Icons\Heroicon;

NotificationCenterManager::registerCategories('admin', [
    NotificationCategory::make('system')
        ->label('Sistema')
        ->icon(Heroicon::Cog6Tooth)
        ->color(Color::Gray)
        ->order(1),
    NotificationCategory::make('security')
        ->label('Segurança')
        ->icon(Heroicon::ShieldCheck)
        ->color(Color::Red)
        ->order(2),
    NotificationCategory::make('backups')
        ->label('Backups')
        ->icon(Heroicon::ArchiveBox)
        ->color(Color::Amber)
        ->order(3),
]);

Disparando Notificações Categorizadas

Para disparar uma notificação vinculada a uma categoria específica e salvá-la no banco de dados para exibição nas abas do painel, utilize o método ->category() em combinação com a API de notificações do Filament:

php
<?php

use Filament\Notifications\Notification;

Notification::make()
    ->title('Backup Concluído com Sucesso')
    ->body('O arquivo de backup diário foi gerado e armazenado de forma segura.')
    ->success()
    ->category('backups') // Macro nativa !
    ->sendToDatabase($user);

Se o método ->category() não for invocado ou for passado como null, a notificação será alocada automaticamente na aba padrão "Geral" e listada na aba "Todas".

Importações e Exportações (Traits Nativa)

Para facilitar a integração com as ações de importação e exportação em segundo plano (Background Actions) do Filament, o labSIS-KIT disponibiliza traits dedicadas no namespace App\Support\NotificationCenter\Concerns\:

  • CategorizesExportNotifications: Redireciona automaticamente notificações de exportação concluída para a categoria 'exports'.
  • CategorizesImportNotifications: Redireciona notificações de importação para a categoria 'imports'.

Exemplo de uso no seu Exporter ou Importer:

php
<?php

namespace App\Filament\Exports;

use App\Models\User;
use App\Support\NotificationCenter\Concerns\CategorizesExportNotifications;
use Filament\Actions\Exports\Exporter;
use Filament\Actions\Exports\Models\Export;
use Filament\Notifications\Notification;

class UserExporter extends Exporter
{
    use CategorizesExportNotifications;

    // A trait se encarrega de adicionar ->category('exports') 
    // automaticamente na notificação enviada ao final do processamento.
}

Boas Práticas no labSIS-KIT

  • ✅ Concordância com o Domínio: Mantenha os IDs de categorias curtos em inglês (ex: 'security', 'billing') e utilize ->label() em português claro para exibição na interface do usuário.
  • ✅ Enums Suportados: O método ->category() e o registro via NotificationCategory::fromEnum() suportam classes BackedEnum do PHP nativamente, permitindo forte tipagem.
  • ✅ Sem Arquivos de Configuração Externos: A configuração padrão do sistema é auto-contida na classe manager (padrão 'general'), evitando poluição de arquivos em config/.
